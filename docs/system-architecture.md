# 系统架构设计

## 1. 系统概述

Bank Transaction A2UI System 是一个基于 **A2UI (AI-to-UI)** 架构的银行交易管理系统。核心创新是将传统的前端开发模式转变为 AI 驱动的动态 UI 生成模式。

### 1.1 设计目标

| 目标 | 描述 |
|------|------|
| 智能化 | AI 理解用户意图，自动生成最适合的 UI |
| 灵活性 | 无需前端修改即可支持新的展示需求 |
| 高效性 | 减少前端开发工作量，提升迭代速度 |
| 可扩展 | 组件化设计，易于扩展新功能 |

### 1.2 核心价值

```
传统模式: 需求 → 设计 → 开发 → 测试 → 上线 (周期长)
A2UI模式: 需求 → AI生成 → 渲染 (周期短)
```

## 7. 扩展设计

### 7.1 新增组件流程

```
1. 创建组件文件
   packages/frontend/src/a2ui/components/NewComponent.tsx

2. 导出组件
   packages/frontend/src/a2ui/components/index.ts

3. 注册组件定义
   packages/frontend/src/a2ui/componentCatalog.ts
   {
     name: 'NewComponent',
     description: '组件描述（AI 理解用）',
     category: 'display',
     props: [...]
   }

4. 添加组件映射
   packages/frontend/src/a2ui/renderNode.tsx
   componentMap['NewComponent'] = NewComponent

5. 更新后端提示词
   packages/backend/src/routes/ai.ts
   添加组件说明
```

### 7.2 新增 API 流程

```
1. 创建路由文件
   packages/backend/src/routes/newRoute.ts

2. 注册路由
   packages/backend/src/index.ts
   app.use('/api/new-route', newRouter)

3. 前端调用
   fetch('/api/new-route', { ... })
```
